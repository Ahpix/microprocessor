# 🔌 다마고치 조작기 브레드보드 배선 가이드 (Breadboard Wiring Guide)

이 문서는 라즈베리파이와 브레드보드(빵판)를 사용하여 **버튼 3개**와 **상태 LED 4개**를 처음 연결하는 초보자도 쉽게 따라 할 수 있도록 정리한 실전 하드웨어 배선 가이드입니다.

---

## 1. 준비물 목록 (BOM)

| 부품명 | 수량 | 권장 사양 / 비고 |
|:---|:---:|:---|
| **라즈베리파이** | 1대 | **Raspberry Pi 4 Model B** (40핀 헤더, 5V/3A USB-C 전원 어댑터 권장) |
| **브레드보드** | 1개 | 400핀(하프 사이즈) 또는 830핀(풀 사이즈) |
| **택트 스위치 (버튼)** | 3개 | 4핀 6x6mm 또는 12x12mm 택트 스위치 |
| **LED** | 4개 | 3mm 또는 5mm (권장 색상: 빨강/주황, 노랑, 초록, 파랑) |
| **전류 제한 저항** | 4개 | **220Ω** (색띠: 빨-빨-갈-금) 또는 **330Ω** (주-주-갈-금) |
| **점퍼선** | 약 12~15가닥 | 암-수(Female-to-Male) 점퍼선 (또는 T-코블러 사용 시 수-수) |

> ⚠️ **중요 주의사항 (부품 보호)**
> - LED는 반드시 **전류 제한 저항(220Ω~330Ω)**을 직렬로 연결해야 합니다. 저항 없이 라즈베리파이 GPIO에 직결하면 **LED가 타버리거나 라즈베리파이의 GPIO 핀이 영구 손상**될 수 있습니다.
> - 본 프로젝트의 버튼은 라즈베리파이의 **내부 풀업 저항(Internal Pull-up)**을 사용하므로, 버튼 측에는 별도의 외장 저항이나 3.3V 전원선을 연결할 필요가 없습니다. (GND에만 연결)

## 2. 부품 기본 원리 및 극성 구분법

### 2.1 LED 극성 구분
LED는 전류가 한쪽 방향으로만 흐르는 극성 부품입니다.
- **긴 다리 (Anode, +)**: 라즈베리파이 GPIO 신호선 (저항 경유)
- **짧은 다리 (Cathode, -)**: 평평하게 깎인 몸통 쪽 다리이며, **GND(접지)**에 연결

```text
       ┌───┐
       │   │  <-- 둥근 플라스틱 캡
       └───┘
       ├───┤  <-- 한쪽 면이 살짝 평평하게 깎여 있음 (음극 쪽)
       │   │
       │   │
      (긴) (짧)
       │   │
       │   └── 음극(-, Cathode) : 브레드보드 파란색(-) GND 레일로 연결
       └────── 양극(+, Anode)   : 저항을 거쳐 라즈베리파이 GPIO 핀으로 연결
```

### 2.2 택트 스위치 (4핀) 핀 구조
택트 스위치의 4개 다리는 내부에서 2개씩 한 쌍으로 이미 연결되어 있습니다.
- 브레드보드의 **가운데 홈(중앙 분리대)**을 가로질러 꽂으면 양쪽 핀이 쇼트되지 않고 올바르게 고정됩니다.
- 스위치를 누르면 분리되어 있던 좌/우 쌍이 서로 통전(도통)됩니다.

```text
       [ 택트 스위치 상단 뷰 ]
           (A)───[홈]───(B)
            │   [ 스위치 ]  │    * A와 C는 내부 연결
            │   [ 누름 버튼 ]│    * B와 D는 내부 연결
           (C)───[홈]───(D)   * 버튼을 누르면 (A,C)와 (B,D)가 연결됨
```

### 2.3 브레드보드 내부 연결 구조
- **파란색(-) 전원 레일**: 브레드보드 가장자리의 긴 줄 전체가 **가로**로 서로 연결되어 있습니다. (공통 GND 버스로 사용)
- **중앙 단자 구멍 (a~e / f~j)**: 각 번호(1, 2, 3...) 열마다 **세로** 5구멍씩 연결되어 있습니다.

우리가 연결할 핀의 위치입니다 (물리 핀 번호 기준).

```text

   (I2C SDA) GPIO 2      [ 3] [ 4] 5V Power
   (I2C SCL) GPIO 3      [ 5] [ 6] GND ───────────────> [★ 브레드보드 공통 GND 버스]
             GPIO 4      [ 7] [ 8] GPIO 14 (UART TX)
                GND      [ 9] [10] GPIO 15 (UART RX)
[★ 버튼 A]   GPIO 17     [11] [12] GPIO 18
[★ 버튼 B]   GPIO 27     [13] [14] GND
[★ 버튼 C]   GPIO 22     [15] [16] GPIO 23 [★ 배고픔 LED]
             3.3V Power  [17] [18] GPIO 24 [★ 행복도 LED]
             GPIO 10     [19] [20] GND
             GPIO 9      [21] [22] GPIO 25 [★ 에너지 LED]
             GPIO 11     [23] [24] GPIO 8
                GND      [25] [26] GPIO 7
             GPIO 0      [27] [28] GPIO 1
[★ 연결 LED] GPIO 5      [29] [30] GND
             ...         [..] [..] ...
```

## 4. 단계별 배선 가이드 (Step-by-Step)

### STEP 1: 공통 접지(GND) 레일 구축
1. 점퍼선(검정색 권장)의 암(Female) 단자를 라즈베리파이 **물리 6번 핀(GND)**에 꽂습니다.
2. 수(Male) 단자를 브레드보드 상단의 **파란색(-) 레일**에 꽂습니다.
   > 이제 브레드보드의 파란색(-) 라인 전체가 라즈베리파이의 GND 역할을 합니다.

---

### STEP 2: 버튼 3개 배치 및 배선

1. **버튼 3개를 브레드보드 중앙 분리대 홈을 가로지르도록 꽂습니다.**
   - 예: 버튼 A는 5~7번 열, 버튼 B는 12~14번 열, 버튼 C는 19~21번 열
2. **GND 연결 (공통)**:
   - 각 버튼의 한쪽 다리(예: 아래쪽 열)에서 점퍼선을 따서 브레드보드의 **파란색(-) 레일**에 각각 연결합니다.
3. **GPIO 신호선 연결**:
   - **버튼 A (방향키 1 / 메뉴 이동)**: 반대쪽 다리 열 ───> 라즈베리파이 **물리 11번 핀 (GPIO 17)**
   - **버튼 B (선택 버튼 / 확인)**: 반대쪽 다리 열 ───> 라즈베리파이 **물리 13번 핀 (GPIO 27)**
   - **버튼 C (방향키 2 / 취소)**: 반대쪽 다리 열 ───> 라즈베리파이 **물리 15번 핀 (GPIO 22)**

---

### STEP 3: LED 4개 및 220Ω 저항 배치 및 배선

각 LED마다 동일한 패턴으로 저항과 함께 배선합니다:
1. **LED 꽂기**:
   - 짧은 다리(음극, -): 브레드보드 **파란색(-) 레일**에 바로 꽂거나, 점퍼선으로 파란색(-) 레일에 연결
   - 긴 다리(양극, +): 브레드보드 중앙 단자 열(예: 30번 열의 e행)에 꽂음
2. **220Ω 저항 연결**:
   - 저항의 한쪽 다리를 LED 긴 다리가 꽂힌 같은 열(예: 30번 열의 d행)에 꽂음
   - 저항의 다른 쪽 다리를 건너편 열(예: 30번 열의 c행 또는 분리대 건너 f행)에 꽂음
3. **GPIO 신호선 연결**:
   - 저항 반대편 다리와 같은 열에서 점퍼선을 라즈베리파이 GPIO 핀으로 연결합니다.

| LED 대상 | 권장 색상 | 양극(+) 저항 연결 GPIO (물리 핀) | 음극(-) 연결 |
|:---|:---:|:---|:---|
| **LED 1 (배고픔)** | 주황/빨강 | **GPIO 23 (물리 16번 핀)** | 파란색(-) 레일 (GND) |
| **LED 2 (행복도)** | 노랑 | **GPIO 24 (물리 18번 핀)** | 파란색(-) 레일 (GND) |
| **LED 3 (에너지)** | 초록 | **GPIO 25 (물리 22번 핀)** | 파란색(-) 레일 (GND) |
| **LED 4 (서버 연결)**| 파랑/백색 | **GPIO 5 (물리 29번 핀)** | 파란색(-) 레일 (GND) |

```text
                                                                       │ (공통 접지 버스)
[ 브레드보드 파란색 (-) 레일 ] <────────────────────────────────────────┴───────
     │          │          │              │             │             │             │
     │(GND)     │(GND)     │(GND)         │(-)          │(-)          │(-)          │(-)
  [버튼 A]   [버튼 B]   [버튼 C]       [LED 1]       [LED 2]       [LED 3]       [LED 4]
  (방향키1)   (선택)    (방향키2)       (배고픔)       (행복도)       (에너지)      (서버연결)

     │          │          │           [220Ω]        [220Ω]        [220Ω]        [220Ω]

   Pin 11     Pin 13     Pin 15         Pin 16        Pin 18        Pin 22        Pin 29
 (GPIO 17)  (GPIO 27)  (GPIO 22)      (GPIO 23)     (GPIO 24)     (GPIO 25)     (GPIO 5)
```

## 6. 전원 인가 전 필수 체크리스트 (합선 방지)

배선을 마친 후 라즈베리파이에 전원 케이블을 꽂기 전에 아래 사항을 반드시 확인하세요:

- [ ] **3.3V / 5V 전원 핀 확인**: 라즈베리파이의 1번(3.3V), 2번(5V), 4번(5V) 전원 핀에 점퍼선이 잘못 꽂혀 있지 않은가? (본 회로는 전원 핀을 쓰지 않고 오직 신호선과 GND만 씁니다.)
- [ ] **저항 누락 여부**: 4개의 LED 모두에 220Ω 저항이 직렬로 연결되어 있는가?
- [ ] **LED 극성 확인**: LED의 긴 다리가 저항(GPIO 쪽)을 향하고 짧은 다리가 파란색(-) GND 레일을 향하고 있는가?
- [ ] **버튼 쇼트 여부**: 버튼의 다리가 엉뚱하게 이웃한 단자와 닿아있지 않은가?
- [ ] **GND 공통 연결**: 라즈베리파이 Pin 6(GND)이 브레드보드 파란색(-) 라인에 확실히 꽂혀 있는가?

## 7. 배선 검증 (단독 테스트 실행)

배선이 완료되면 라즈베리파이 터미널에서 제공된 테스트 스크립트를 실행하여 정상 작동하는지 확인합니다.

### 7.1 LED 테스트
LED 4개가 하나씩 켜지고, 깜빡이고, 꺼지는지 확인합니다:
```bash
python3 -m hardware.tests.test_leds
```
> *만약 특정 LED가 켜지지 않는다면?*  
> 1) LED 다리가 반대로 꽂혔는지(극성 역전) 확인  
> 2) 점퍼선이 물리 핀 번호와 BCM 번호를 혼동하여 엉뚱한 핀에 꽂혔는지 확인

### 7.2 버튼 테스트
버튼을 하나씩 눌러 터미널에 `Button A`, `Button B`, `Button C`가 1번씩 찍히는지 확인합니다:
```bash
python3 -m hardware.tests.test_buttons
```
> *만약 버튼을 누르지도 않았는데 계속 이벤트가 발생하거나 반응이 없다면?*  
> 1) 버튼이 브레드보드 홈에 정확히 장착되었는지 꾹 눌러보기  
> 2) GND 연결선이 헐겁지 않은지 확인
